Лимиты использования и ответов

Здесь можно подготовить черновик настроек. Работающий бот использует текущую версию до отдельного выпуска.

Для каждого пользователя. Текущее значение по умолчанию — 20 секунд.
Лимит для людей. Увеличение может повысить затраты на модель.
Отдельный лимит при включённом автоматическом тестировании.
Включает токены рассуждения; это не длина видимого текста.
Больший контекст помогает уточнениям, но увеличивает число входных токенов.

Приостановка в разрешённых чатах

Можно выбрать только чаты, назначенные ассистенту. Для применения паузы в отдельном чате потребуется отдельное изменение работающей системы.
