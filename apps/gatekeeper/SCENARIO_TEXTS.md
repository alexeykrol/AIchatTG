# Реплики Telegram Gatekeeper

Это простой редакторский файл. Здесь нет JSON и служебной конфигурации.
Меняйте только текст после меток `Реплика:`, `Кнопка:`, `Ссылка:` и
`Подпись ссылки:`.
Идентификатор в заголовке нужен, чтобы безошибочно перенести реплику в файл,
который читает бот.

Граница этого каталога: здесь находятся только меняющиеся по точке сценария
реплики, кнопки и ссылки, которые Gatekeeper отправляет участнику или
администратору. Неизменяемая оболочка интерфейса — названия вкладок, заголовки
страниц, подписи показателей и технические HTTP-ошибки — версионируется вместе
с кодом и не является репликой сценария.

## Ветка A — оплата через Tribute, пользователь известен в Telegram

### `group_invitation` — оплата подтверждена, приветствие в общем чате

Реплика:

👋 {{user_mention}}, оплата подтверждена — добро пожаловать!

Чтобы завершить подключение к сообществу, нажмите кнопку ниже, а затем в личном чате с ботом нажмите Start. Это обязательный шаг: без него бот не сможет отправить вам инструкцию и зафиксировать завершение онбординга.

Кнопка:

Начать онбординг

### `start_missing_token` — бот открыт напрямую, без персональной ссылки

Реплика:

Эта инструкция доступна по персональной кнопке из приветственного сообщения в чате. Вернитесь в чат и нажмите «Начать онбординг».

### `start_invalid_token` — персональная ссылка недействительна или чужая

Реплика:

Эта персональная ссылка недействительна или предназначена другому участнику. Используйте кнопку из своего приветственного сообщения.

### `start_payment_not_confirmed` — Tribute не подтвердил оплату

Реплика:

Для этой ссылки не найдено подтверждение оплаты через Tribute. Онбординг не начат. Если вы уже оплатили участие, дождитесь нового персонального приглашения или обратитесь к администратору.

### `start_expired_token` — срок персональной ссылки истёк

Реплика:

Срок действия персональной ссылки истёк. Обратитесь к администратору, чтобы получить новую ссылку.

### `start_already_completed` — повторный Start после завершения

Реплика:

Ваш онбординг уже завершён. Дополнительных действий сейчас не требуется.

## Служебные события без пользовательской реплики

### `site_registration_received` — сайт подтвердил регистрацию

Реплика:

Нет. Gatekeeper принимает подписанный webhook, создаёт один email-онбординг и передаёт Zapier минимальные данные для письма.

### `zapier_onboarding_completed` — онбординг завершён

Реплика:

Нет. Gatekeeper один раз отправляет в Zapier служебное событие о завершении. Пользователь получает финальную реплику из своей ветки выше.
