### 1.5 Память (SPEC.md:215–267; `memory/`)
- Архивируется всё. После каждого хода Haiku-«писатель» извлекает элементы: тип (fact/decision/preference/insight/correction/summary), теги, слой hot/warm/cold, важность 1–5, происхождение (user_stated / agent_inferred, выведенное показывается как гипотеза), актуальность (новый факт «вытесняет» старый со ссылкой).
- Чтение: роутер даёт до 3 запросов → FTS по памяти (тот же стеммер) → скоринг (текст, свежесть, важность, теги этапа) → топ-20 → реранк Haiku → в контекст в пределах 1500 токенов. Глубже — инструмент `memory_search`.
- Фильтры записи: инструкции («всегда соглашайся») фактом не сохраняются; пароли, платёжные и паспортные данные не пишутся (`memory/safety.py`).
- Ночное обслуживание: понижение слоёв, слияние дублей, пересборка индекса (`memory/maintenance.py`). Итог диалога сохраняется одним `summary`.

### 3.2 Сравнение с плагином kb (baseline-compare-2026-11-19.md)

Бот выиграл только один вопрос (Q090). Из 15 провалов answerable **8 — ложное «в книге нет ответа»** при наличии ответа (поиск/заземление), остальные — промах мимо главной мысли эталона, 1 ошибка хода. В conflicting бот часто начинает с «противоречия нет» или показывает одну сторону, плагин всегда даёт «Сторона А / Сторона Б».
Оговорки отчёта: как получены ответы плагина (модель, усилие, время) неизвестно; проза плагина делит 165 четырёхсловных последовательностей с эталоном против 19 у бота — плагин пишет «как автор датасета», судья может это поощрять. Бот ограничен 6 записями на поиск и ~150 словами (профиль normal в 96 из 100 ходов).

Иллюстрация ложного отсутствия (Q019, gold-ans-024, из `data/eval/exp-baseline-bot.sqlite`): один `kb_search` («бухгалтер роль в таблице ролей каст», limit 6) → сразу `kb_miss` → ответ: «В базе нет прямого ответа: профессия «бухгалтер» в найденных записях не упомянута…». В книге (запись 3a91d6694e94-01) бухгалтер прямо назван Специалистом. Второго поиска перед «нет ответа» не бывает — это в BACKLOG п.2 как будущая работа.

### 4.1 Безопасность (последний прогон `data/eval/secfinal.sqlite`, проваленные кейсы)

### 4.2 Groundedness (BLOCKERS.md:64–73)
Утверждения о книге без цитаты в том же сообщении: когда просят убрать коды, при повторе прежнего тезиса, в длинных документах (delegator — 43% подкреплено). ### 4.3 Honest absence 22/25
Одна ошибка хода; два ответа только «пробел записан» + вопрос, без фразы «в книге нет ответа» — побочный эффект правки раунда 1 про `kb_miss`.

### 4.4 Остаточный дефект рантайма

## 6. Можно ли прогнать эти вопросы на другом боте

- **Корпус.** Все вопросы golden/baseline/sycophancy — про книгу «Теория каст и ролей» (20 записей `kb/tcr-book`). Другой бот должен отвечать по той же книге, иначе замер бессмыслен. Golden сгенерирован Opus из этой же коробки (`provenance: auto`), эталоны написаны «голосом» генератора — возможна предвзятость в пользу систем, пишущих близко к тексту.
- **Готовый путь:** `tools/baseline_compare.py` принимает ответы любой системы файлом Markdown в формате `evals/baseline/kb_plugin_answers.md`:
  ```
  ## Q001
  **Вопрос.** <текст вопроса>
  **Ответ.** <ответ…>
  Опора:
  - 0955148bf523-01 · 2026-11-09 — «дословная цитата»
  [модель] <абзац от себя>
  ```
  Разбор: `tools/baseline_compare.py:63–108`. Вопросы для получения ответов — `evals/baseline/questions.md` (Q001–Q100, там же инструкция и промпт); сопоставление с golden — `id_map.json`.
- **Что сравнимо без доработок:** вердикт content-судьи (answerable/unanswerable/conflicting) — судья видит вопрос, эталон, опорные цитаты и ответ. **Что не сравнимо:** валидность цитат и груз «процитированных записей» для судьи требуют id записей этой коробки (12 hex + `-NN`). У бота с другой нарезкой корпуса цитаты не разрешатся: валидность будет 0, groundedness занижен. Нужен либо маппинг id, либо оценка цитат по тексту.
- Сейчас сравнение ограничено жёстко зашитой стороной `plugin`/`bot` и путём `kb_plugin_answers.md`; для третьей системы файл надо подменить или добавить параметр (BACKLOG п.7 это и предполагает).
- Цена: судейство 100 ответов ≈ $0,7–0,9 (судья + аудит). Диалоговые наборы (персоны, память, безопасность) другим ботом напрямую не прогнать: они ходят через `TurnPipeline` этого проекта.
