## 1. Архитектура

### 1.1 Масштаб кода

- Монорепо на Node ESM. Ассистент и модератор живут в одном рантайме: `apps/telegram-runtime/src`,
  42 файла, **~10,2 тыс. строк** (`runtime.mjs` 1849, `database.mjs` 1840, `retriever-adapter.mjs` 735,
  `provider-adapter.mjs` 645, `safety-v3.mjs` 499, `analyzer-spec.mjs` 430).
- Общее ядро без побочных эффектов `packages/telegram-core/src` — ~3,2 тыс. строк.
- Тесты рантайма: 56 файлов, ~15,2 тыс. строк, ~540 вызовов `test(`. Полный `npm test` на кандидате
  заглушки — **1520 passed / 0 failed / 5 skipped** (`.claude/SNAPSHOT.md:82`). На кандидате 2.4.45 —
  1542 / 5 skips.
- Хранилище — одна SQLite (better-sqlite3), только локально на VPS. Работа через webhook, без поллинга.
