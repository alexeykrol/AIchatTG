## Разбор

### A2C-01. Раннер автономной сборки по фазам
Скрипт на каждую фазу запускает свежую безголовую сессию `claude -p` и сам выполняет команду гейта: прошёл — тег и push, нет — хвост вывода уходит следующей попытке. Три попытки, затем фаза «заблокирована». Лимит подписки и сбой сети попыткой не считаются.
- Где: `tools/runner.py:44-61, 141-181, 350-372, 481-592`; `tools/phases.yaml`; `PLAN.md:5-145`; `STATE.md`.
- Зрелость: `tests/unit/test_runner.py` (15). Вживую десять фаз прошли за 95 минут сессий; P8 — 170 минут, три попытки, блок.
- AIchatTG: нет — `AIchatTG/.claude/workflows/` не существует, в `AIchatTG/scripts/aichattg/` раннера нет. Это условие 1 карты.
- Риски: привязан к флагам CLI 2.1.326 и подписке владельца; слабый гейт он пропустит.

### A2C-02. Изоляция сессий сборки
Домашние `CLAUDE.md` и `rules/` подгружаются в каждую сессию как проект-предок. Снимает их только пара: флаг `--setting-sources project,local` и настройка `claudeMdExcludes`.
- Где: `HANDOFF.md:59-98`; `DECISIONS.md:42-49`; `.build/isolation.json`.
- Зрелость: замер — по умолчанию ~163 000 токенов на старте, только флаг ~158 000, только исключения ~67 000, оба ~33 000.
- AIchatTG: нет — grep `claudeMdExcludes|setting-sources` по `AIchatTG/scripts/aichattg` и исходникам приложений дал 0 файлов. Впятеро меньший стартовый контекст каждому воркеру.
- Риски: вместе с правилами уходит их защита.

### A2C-03. Правила честности гейтов
Нельзя понижать порог, править набор данных, промпт судьи или тест ради зелёного гейта. Гейт пройден, только если его команда реально выполнилась. Результаты на заглушках подписываются.

## Идеи, которых владелец мог не видеть

Решения, которые модель приняла сама. Записанное «почему» приведено.

**Сборка**

1. **Гейт запускает раннер, а не сессия.** «The runner checks the gate itself, whatever the session claimed» (`tools/runner.py:481-592`): сессия может ошибаться в том, что сделала.
2. **Код выхода 5 у pytest — провал.** Нет собранных тестов — гейт не пройден, поэтому фаза не может пройти без собственных тестов (D-010, `DECISIONS.md:98-103`).
3. **Сборка на подписке, приложение на ключе с лимитом.** Раннер вырезает ключ приложения из окружения сессии (`tools/runner.py:61`): сборка не тратит деньги API.
4. **Блок не останавливает сборку.** Фаза с `fallback` после блока пропускает зависимые дальше; `manual` ждёт владельца; отчёт помечен `always_run` (`tools/runner.py:141-181`).
5. **Чинит более сильная модель, чем пишет.** Первая попытка — дешёвая модель, повтор — `fix_model` (`STATE.md`, P8: sonnet → opus).
