# Правило отказа, независимый набор вопросов и вектор — замеры 20.11.2026 (вечер)

Все замеры бесплатные: настоящий путь поиска без модели ответа, пакет книги
`output/eval/tcr-book-v4/packages/tcr-59025ab82058` (20 записей, 60 кусков). Боевой код не менялся:
переключатель правила отказа по умолчанию выключен и в бой не подключён.

## Инструменты

- Переключатель: `node scripts/eval/ask-offline.mjs --mode retrieval --package <пакет> --out <абс. путь>
  --no-concept-gate refuse|pass [--max-entries N] [--max-context-tokens N] [--donor <набор вопросов>]`.
- Мерка «нужное место перед моделью»: `python3 scripts/eval/passage_coverage.py <прогон>… --package <пакет>
  [--cases <cases.jsonl>] [--tsv <файл>]`. «Запись» — в контексте есть кусок нужной записи; «само место» —
  в контексте есть кусок, содержащий опорную цитату.
- Независимый набор: `scripts/eval/heldout/tcr-heldout-v1/` (форма донорского стенда: `evals/golden/cases.jsonl`,
  `evals/baseline/id_map.json`, номера H001–H050). 30 вопросов с ответом (10 терминами книги, 20 бытовыми
  словами; 8 из бытовых требуют двух записей), 12 двусторонних, 8 без ответа в книге. Написан воркером Codex
  по полному тексту пакета, без доступа к старому набору и к отчётам; 62 цитаты проверены дословно.
- Вектор: `docs/reports/2026-11-20-search-architecture/vector_experiment.py`, локальная модель
  `paraphrase-multilingual-MiniLM-L12-v2` (маленькая, старая — нижняя граница), окна по три предложения.

## Карточки поиска

Карточки (303 вопроса и 486 бытовых формулировок на 60 кусков) добавлены в поле обогащения
`chunks.search_alias` копии пакета (`scripts/eval/apply_search_cards.py`). На старом наборе результат не
изменился ни с правилом (42/60), ни без него (55/60). Причина известна: оценка совпадения считается только
по тексту куска, и кандидат, найденный по карточке, понижается как «совпадение только в заголовке». Статус
опыта — **inconclusive**: нужна опция учёта карточек в оценке совпадения.

## Оговорки

- Старый набор составлен автоматически близко к тексту книги — он льстит поиску по словам. Независимый
  составлен с требованием не использовать термины книги в 20 бытовых вопросах — он, вероятно, строже жизни.
  Реальное распределение вопросов неизвестно.
- Независимый набор мал (30 + 12 + 8) и написан одной моделью.
- Вектор измерен на уровне записи, а не места, и на слабой модели.
- Качество ответов не измерялось: это покрытие контекста, а не оценка судьи.
