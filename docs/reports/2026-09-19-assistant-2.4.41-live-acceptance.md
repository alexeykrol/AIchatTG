branch is the legacy router, so the test-chat dispatch boundary must **not**
be presented as the answer that group necessarily receives.

and has no exact website negative example. Selecting that domain for
«Ты можешь сделать сайт?» is therefore not, by itself, a proven product defect.

site creation, code writing and development are not available bot functions,
