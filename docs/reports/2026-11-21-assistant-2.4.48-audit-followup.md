## 2. Эксперимент с уже найденной опорой

В новой доменной политике `book` есть указание «resolve the paradox through the book’s logic», а общий текст разрешает приписывать автору связку только при наличии соответствующего места. Локальная сборка `answerSystemPrompt` с корректным `book` включает **оба** указания. Для `content` первое отсутствует. SHA-256 полученных system prompt на этом SHA — `86afaa029467f212a84514e44b3a965c301e300ef2bc4706b19442e2933522ed` для книги и `86698da91400184a29bc46ae2c29a2b87bb787aeb399957cc5d964574ce6130b` для курса. Содержательная коллизия подтверждена, её влияние на ответы ещё предстоит измерить. Штатный `scripts/eval/lib/answer-path.mjs` выбирает `content` и при фиксированном контексте подаёт его через источник курса. Для исследования версии 2.4.48 базу и все экспериментальные варианты следует провести через одинаковый `book` и сохранить хеш фактически отправленного промпта. Для исторической реплики P уместно заморозить историческую конфигурацию. ## 4. Почему тест с курсом даёт 14/15

Одни тесты с одним реальным пакетом курса и value-срезом под Node 20.20.0 дали `f6c7b05^` — 15/15, `f6c7b05` — 14/15, `134955627f9e` — 14/15. Единственное падение на строке 123 ожидает `abstained=true`. Теперь при пустой выдаче выбранного домена по правилу владельца 20.11 ход продолжает обработку с `in_domain_gap`. В этом сухом сценарии реально получены 0 фрагментов, `abstained=false`, `teach:course-content-v1`, журнал дефицита и передача пустого контекста подмене модели. По этому случаю следует обновить всю группу ожиданий о результате, сохранив проверки пустой выдачи и журналирования. Ошибка допуска самого пакета остаётся технической ошибкой.
