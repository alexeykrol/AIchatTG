# Пакет решений владельца перед автономной работой

**Статус:** предложение агента, 19.11.2026. Что ждёт твоего слова — в разделе 7.
**Назначение:** собрать в одном месте всё, что нужно решить один раз, чтобы дальше работа шла
без остановок: деньги, качество, стопы, данные пользователей, место разработки, каталог.

## 1. Бюджет и кредиты

### 1.1. Факты (проверено 19.11.2026)

- Твой тариф — **Ultra**, к нему положено **$200 кредитов API в месяц** (скриншот владельца
  19.11.2026). Кредиты **привязаны с 17.10.2026** к организации Console «Alex's Individual
  Organization»; следующее начисление — 8-го числа (8.12.2026). Остаток виден только в Console →
  Billing. Раньше здесь ошибочно стояло «Max, $100»: локальная настройка показывала другой тариф.
- Кредиты надо **один раз привязать** к организации Console: claude.ai → Settings → Billing →
  раздел API credits → Link organization. Сменить привязку самому нельзя, только через
  поддержку.
- **Не переносятся:** неиспользованное сгорает в конце расчётного периода.
- **Покрывают:** Claude API (включая пакетный режим), Agent SDK, Managed Agents, Playground.
- **Не покрывают:** Claude Code — ни интерактивный, ни запуски из расширения IDE и приложения,
  даже с `-p`; дополнительное использование сверх лимитов подписки.
- **Тратятся первыми,** до купленных кредитов. Баланс общий на все ключи организации.
- Все три найденных ключа Anthropic (News, чат поддержки на сайте, стенд `agi2claude`)
  принадлежат **одной организации Console**. Проверено бесплатным запросом списка моделей;
  ключи не печатались. Третий ключ дописан в реестр `operations/creds/REGISTRY.md`.
- **Привязаны ли кредиты, я не вижу** — это видно только тебе на странице Billing.
- Текущий ассистент AIchatTG работает на моделях OpenAI. Там кредитов нет.

Источники: platform.claude.com/docs/en/about-claude/api-credits-for-subscribers;
support.claude.com/en/articles/17154008.

### 1.2. Главный вывод

Организация одна, и в ней уже идёт боевой расход (News, чат поддержки). Поэтому после
привязки кредиты расходуются полностью сами: первые $100 любого расхода организации в месяц
закрываются ими. Что именно их съест — прод или наши прогоны — на итог не влияет: экономия
$100 в месяц на организацию в целом. Если кредиты не привязаны, эти $100 сгорали каждый
месяц.

### 1.3. Три кармана

| Карман | Цена для тебя | Что через него идёт |
|---|---|---|
| **А. Подписка Max** | уже оплачена, сверху ноль | моя работа и все субагенты (проектирование, код, чтение, исследования); дженерик с плагином — сторона сравнения, вход по подписке без ключа; разовые офлайн-суждения: ключи ответов, карточки ролей, инструкции судьи |
| **Б. Кредиты API** | $100 в месяц, уже включены | наш сервис под испытанием на моделях Claude, модель-судья, синтетические пользователи |
| **В. Живые деньги** | по факту | расход Anthropic сверх $100 в периоде; OpenAI — судья другого вендора для перепроверки и прогоны нынешнего ассистента как точки сравнения |

Ограничение кармана А: недельные лимиты подписки общие с остальными твоими проектами. Большие
прогоны дженерика идут партиями и с потолком параллельности, чтобы не съесть твою рабочую
неделю.

Почему судья идёт через API, а не через подписку: ему нужна закреплённая модель без
системной инструкции Claude Code и пакетный режим. Иначе результаты не воспроизводятся.

### 1.4. Как удешевляется платная часть

- **Пакетный режим** для всего, что не требует ответа сразу (судья, одноходовые ответы
  теста): минус 50% по документации.
- **Кэширование** повторяющегося входа: инструкция судьи, записи базы.
- **Модель по задаче:** дешёвая — диспетчеру и синтетическому пользователю, сильная —
  отвечающему и судье.
- **Сначала прибор, потом расход:** перед каждым платным прогоном судья бесплатно проверяется
  на заведомо плохих ответах, а полный прогон идёт после пробы на 10 вопросах.

### 1.5. Коридор (предложение, пересчитан под программу консолидации)

| Шаг программы | Что покупаем | Как считали | Потолок |
|---|---|---|---|
| 1. Первый честный замер | нынешний ассистент отвечает на 100 вопросов стенда по книге; судья; два прогона ради шума | ответ до $0,14 (OpenAI, как в проде) × 100 × 2 ≈ $28; судейство файла ≈ $1 | $30 |
| Судья и калибровка | проверка судьи на заведомо плохих ответах; 30 пар для владельца; перепроверка выборки судьёй другого производителя | десятки вызовов судьи | $20 |
| 2. Ядро ответа: паритет | около 8 рычагов поиска и ответа по одному, каждый на 100 вопросах дважды, на Claude и на OpenAI | ответ $0,007–0,03 + судья ≈ $0,01; 8 × 2 × 2 × 100 ответов | $120 |
| 3. Трудный тест: превосходство | 250–300 вопросов (реальные из прода, на несколько записей, противоречия), два варианта, два прогона, судьи трёх слоёв | ответ на большой базе ≈ $0,05 + судьи ≈ $0,05 | $150 |
| 4. Синтетические пользователи | роли читателей, 200–300 разговоров по нескольку ходов | цикл разговора ≈ $0,1–0,2 | $50 |
| Запас | перерасход шагов, повторы после правок | — | $80 |
| **Всего** | из них OpenAI — до $40 | | **$450** |

Не входит и стоит ноль сверху: работа агента и субагентов, ответы дженерика с плагином и
составление ключей ответов — через подписку. Стоимость прода (ассистент в Telegram) — отдельная
статья, коридор её не трогает.

Кредиты API ($100 в месяц) закрывают первые $100 расхода Anthropic в каждом расчётном периоде.
Если программа растянется на два периода, из своих денег уйдёт около $250 вместо $450.

Минимальный вариант: только шаги 1, 2 и судья — $170 с запасом $30, итого $200. Этого хватает,
чтобы получить ответ «догнали дженерик или нет», и уже после него решать про шаги 3–4.

Оценки — порядок величины по прошлым замерам: стенд `agi2claude` потратил на оценки $126,
цена ответа там $0,019 на Claude и $0,007 на OpenAI; ответ нынешнего ассистента — до $0,14;
один разговор синтетического пользователя в `agi` стоил около 9 центов.

Правила коридора:

- Потолок шага — учёт, а не тормоз: перерасход шага беру из запаса и записываю.
- Общий потолок — стоп: дальше только по твоему слову.
- Каждый прогон пишет фактическую стоимость в журнал; потолок зашит в код стенда.
- Перед каждым полным прогоном — проба на 10 вопросах; дорогой рычаг, не давший прироста,
  дальше не прогоняется.

### 1.5а. Решение владельца 19.11.2026: паритет — гипотеза, деньги — траншами по $20

Слова владельца: «на самом деле это твоя гипотеза: мы потратим деньги и достигнем паритета.
Поэтому правильный подход будет таким: мы должны потратить деньги и понять, достигли мы
паритета или нет. […] надо разбить на части, скажем, по 20 баксов. Если выяснится, что за
20 баксов на небольшом количестве прогонов мы уже достигаем паритета, для надёжности потратим
ещё 20 баксов. Тогда нет смысла тратить всё. […] Только после этого будем обсуждать с
остальными.»

Как исполняется:

- Сейчас в работе только шаги 1 и 2 (замер и паритет). Шаги 3–4 и их бюджет обсуждаются после
  ответа «паритет достигнут или нет».
- Деньги идут траншами по $20. После каждого — стоп и короткий отчёт владельцу: что куплено,
  цифры против дженерика, шум, сколько потрачено всего, что предлагается на следующий транш.
  Следующий транш — по слову владельца.
- Паритет на малой выборке подтверждается ещё одним траншем на полном наборе, дважды.
- **Решение владельца 19.11.2026, позже:** первый транш — **$40**, «бери из кредита». Значит,
  отвечающая модель и судья в этом транше — Claude (кредиты не покрывают OpenAI). После
  транша — стоп, анализ, обсуждение; дальше решает владелец.
- Подготовка без расхода (загрузка книги, вход «вопрос → ответ с номерами записей», подключение
  судьи, проверка судьи на заведомо плохих ответах без вызовов) идёт сразу и денег не требует.

### 1.6. Что сделать тебе

1. **Проверить привязку кредитов** (минута): claude.ai → Settings → Billing → API credits. Если
   там кнопка Link organization — привязать ту единственную организацию Console, где лежат
   ключи. Если уже привязано — ничего не делать.
2. **Завести отдельное рабочее пространство под прогоны** (три минуты, по желанию): Console →
   Workspaces → новое пространство с месячным лимитом расходов $300, ключ из него положить в
   `~/Code/operations/creds/secrets.env`. Тогда превысить коридор нельзя физически. Если не
   заведёшь — беру существующий ключ стенда `agi2claude` и держу потолок кодом.
3. **Назвать коридор:** $450 всего (до $40 на OpenAI), минимальный вариант $200 — или свои числа.

## 3. Стопы (принято со слов владельца 19.11.2026)

Стопов два вида: **деньги** и **любой публичный выпуск**.

- расход сверх общего коридора;
- прод: деплой, вебхук, секреты, миграции, действия от имени бота;
- публичный выпуск плагина и подача в каталог Anthropic;
- цены для пользователей.

Всё остальное — без остановок и без промежуточных докладов; состояние пишется в файлы.

## 4. Данные пользователей и согласие (принято: это не стоп, а следование закону)

Слова владельца 19.11.2026: телеметрию без идентификатора пользователя собираем, как все
софтверные компании; данные, нужные, чтобы помочь самому пользователю, — по предложению и
согласию: согласился — получает больше, отказался — не получает; основа — закон, с учётом
Калифорнии; проработка — `~/Code/GrokBot/Legal`.

Что в этом документе на самом деле (выжимка:
`docs/reports/2026-11-19-research/consent-model-grokbot-legal.md`):

- Это аудит черновика политики от 17.11.2026, не готовая политика. Согласие по явному «да»
  подтверждено и описано подробно.
- Правила о свободной телеметрии в нём нет. Про запись текстов вопросов и про цель «улучшение
  базы знаний» в нём тоже ничего нет.

Поэтому закладываю так [агент]:

- **Без согласия** на сервере остаются только обезличенные события: был ли ответ, вид «нет
  ответа», номера задетых понятий базы, время. Текста вопроса в них нет — в нём самом могут
  быть личные сведения.
- **По согласию** сохраняются текст вопроса, ответ и контекст. Согласие оформляется по
  требованиям аудита: фиксированный текст с версией, явное «да», запись на сервере.
- Текст политики перед публичным выпуском читает калифорнийский юрист — этого требует сам
  аудит. Публичный выпуск и так стоп.
